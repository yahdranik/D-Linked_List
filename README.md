# Двусвязный список

_Двусвязные списки_  — это базовая структура данных, представляющая собой цепочку взаимосвязанных узлов.
Каждый узел содержит два указателя: один — на предыдущий элемент списка, другой — на следующий. 
**Интерфейс** позволяет добавлять и удалять элементы, обращаясь к ним по индексу в списке. Также реализованы функции для инициализации и удаления списка, механизм проверки корректности структуры и другие вспомогательные функции, полезные при отладке.

## Технологии

* _Graphiz_ - язык для написания автоматической визуализации графов
* _HTML_    - язык разметки для создания и структурирования содержимого веб-страниц в браузере
* _GNUPLOT_ - программа для построения научных графиков, функций и визуализации данных

## Возможности 

* Хранение и структурирование данных
* Перемещение по данным в двух направлениях: вперед и назад
* Удаление и добавление элемента за константное время (в будущем, пока что O(n))

## Как запустить программу
### Пользовательский двусвязный список

* Установить WSL
'''
wsl --install -d Ubuntu
'''

* Установить компилятор и Graphviz:
'''
sudo apt update
sudo apt install build-essential graphviz
'''

* Скомпилировать программу
'''
Doubly_Linked_List/d_list.sh
'''

* Запустить программу
'''
./Doubly_Linked_List/mimimi.exe
''''

* Открыть HTML отчёт

#### Программа сравнения производительности для двух версий реализации двусвязных списков: массив структур и структура массивов
* Установить GNUPLOT 
'''
sudo apt install build-essential gnuplot
'''

* Скомпилировать программы для SLOWLY, QUIK версий и общbq MAIN для получения гистограммы сравнения производительностей
'''
Doubly_Linked_List/SLOWLY_LIST/slowly_d_list.sh

Doubly_Linked_List/QUICK_LIST/quick_d_list.sh

Doubly_Linked_List/myscriptt.sh
'''

* Запустить программу
'''
./mimimi.exe
'''

* Открыть итоговый файл histograms.png
