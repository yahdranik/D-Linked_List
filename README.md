# Двусвязный список

_Двусвязные списки_  — это базовая структура данных, представляющая собой цепочку взаимосвязанных узлов, каждый из которых содержит два индекс-указателя: один — на предыдущий элемент списка, другой — на следующий. В отличие от того же односвязного списка, двусвязный дает более гибкое управление данными. 
**Интерфейс** позволяет добавлять и удалять элементы, обращаясь к ним по индексу в списке. Также реализованы функции для инициализации и удаления списка, механизм проверки корректности структуры и другие вспомогательные функции, полезные при отладке, например - графический Dump.

## Используемые технологии

* _Graphiz_
* _HTML_
* _GNUPLOT_

## Возможности 

* Хранение и структурирование данных
* Перемещение по данным в двух направлениях: вперед и назад
* Удаление и добавление элемента за константное время (в будущем, пока что O(n))

## Реализованные функции

| Сигнатура функции | Выполянемые задачи |
| --- | --- |
| `list_init`| Создание и нициализация списка |
| `list_destroy` | Очистика и удаление списка |
| `list_append` | Добавление элемента в список по индексу. Чтобы добавить в начало, в поле index нужно передать 0, в конец - size |
| `list_delete` | Удаление элемента из списка по индексу. Чтобы удалить первый элемент, нужно передать в поле index 0, последний - size -1 |
| `list_verify` | Проверка корретности списка |
| `list_verify_occupied` | Проверка корректности ячеек занятых элементов списка. Является вспомогательной функцией для list_verify |
| `list_verify_free` | Проверка корректности ячеек свободных элементов списка. Является вспомогательной функцией для list_verify |
| `list_realloc_up` | Увеличение вместимости списка. Является вспомогательной функций list_append |
| `find_index_loc` | Поиск "физического" индекса элемента по его индексу в списке |
| `list_testing` | Тест программы |
| `list_dump` | Графический и текстовый вывод состояния списка |

## Графический Dump списка
Графический вывод состояния списка сильно помогает при отладке программы, которая использует двусвязные списки, и помогает визуализировать данные из стуктуры. Узел HEAD указывает на начало списка (его первый элемент), узел TAIL - на конец списка (последний элемент).

## Как запустить программу
### Пользовательский двусвязный список

* Установить компилятор и Graphviz:
```
sudo apt update
sudo apt install build-essential graphviz
```

* Скомпилировать программу
```
Doubly_Linked_List/d_list.sh
```

* Запустить программу
```
./Doubly_Linked_List/mimimi.exe
```

* Открыть HTML отчёт

### Программа сравнения производительности для двух версий реализации двусвязных списков: массив структур и структура массивов

* Установить GNUPLOT 
```
sudo apt install build-essential gnuplot
```

* Скомпилировать программы для SLOWLY, QUIK версий и общий MAIN для получения гистограммы сравнения производительностей
```
Doubly_Linked_List/SLOWLY_LIST/slowly_d_list.sh

Doubly_Linked_List/QUICK_LIST/quick_d_list.sh

Doubly_Linked_List/myscriptt.sh
```

* Запустить программу
```
./mimimi.exe
```

* Открыть итоговый файл histograms.png
